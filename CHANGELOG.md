# Changelog

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/).
Номера версий — по [SemVer](https://semver.org/lang/ru/), стадии — alpha → beta → rc → релиз.

## [[0.1.6] — 2026-09-27]

### Добавлено
- Новое поле `settingsEntry` в `widget.manifest.json` (на верхнем уровне и/или
  на уровне конкретной версии в `versions[]`, по аналогии с `minAppVersion`) —
  позволяет автору виджета подключить собственную встроенную страницу
  настроек вместо автоформы по `configSchema`. Контракт — `SYSTEM_WIDGET_STYLE.md`,
  раздел 11.
- Встроенные настройки открываются прямо внутри окна FoxFire Hub, во
  вкладке "Загруженное", в `<iframe>` — без отдельного окна ОС. Обмен данными
  идёт через `window.postMessage` (`type: "foxfirehub:settings-saved"`), а не
  через Tauri-событие.
- `src/utils/embeddedSettings.ts` — разрешение `settingsEntry` для установленной
  версии виджета и проверка формата входящих сообщений.
- `src/components/DownloadedPanel.tsx` и `src/components/WidgetSettingsPanel.tsx` —
  новый вид вкладки "Загруженное": список установленных виджетов слева, панель
  настроек выбранного справа.
- `src/components/AutoSettingsForm.tsx` — старая автоформа по `configSchema`,
  вынесена в отдельный компонент, используется теперь и в новой панели настроек.
- Добавлена простая анимация загрузки

### Изменено
- Настройки виджета убраны из модалки установки (`WidgetModal.tsx`, раздел
  "Моды"/карточки) — она теперь отвечает только за установку, выбор версии,
  архив версий и удаление. Вместо блока настроек — подсказка со ссылкой на
  вкладку "Загруженное".
- Виджет `unified-chat`, версия `2.0.0` — `settings.html` теперь подключён
  как `settingsEntry` и умеет сохранять настройки живьём через `postMessage`
  в FoxFire Hub (раньше требовалось открытие в отдельном окне через Tauri-событие,
  оставлено как запасной вариант). Версия `1.0.0` того же виджета `settingsEntry`
  не объявляет и по-прежнему получает автоформу — пример разделения поддержки
  функции между версиями одного виджета.

## [0.1.5] — 2026-09-26

### Добавлено
- Реальный запуск установленного виджета по кнопке "Запустить" — открывает
  `index.html` виджета в отдельном окне FoxFire Hub (`src/utils/widgetLaunch.ts`,
  `WebviewWindow`), с передачей сохранённых настроек через query-параметры URL.
  Повторный клик, пока окно виджета уже открыто, просто фокусирует его.
- Кнопка "Скопировать ссылку для OBS" в модалке виджета — копирует в буфер
  обмена готовую `file://`-ссылку на `index.html` виджета с теми же
  настройками, для вставки в источник "Браузер" в OBS напрямую.

### Изменено
- В `tauri.conf.json` и `src-tauri/Cargo.toml` включены права `window > create`
  и `clipboard > writeText`, нужные для запуска виджета в отдельном окне и
  копирования ссылки.

## [0.1.4] — 2026-09-25

### Добавлено
- Реальное скачивание и распаковка файлов виджета вместо имитации установки
  (Rust-команда `download_and_extract_widget`).
- Реальное удаление файлов виджета, с выбором "сохранить настройки" или
  "удалить полностью" (Rust-команда `remove_widget_dir`).
- Вкладка "Загруженное" в нижней навигации со списком скачанных виджетов.
- Постоянное локальное состояние приложения (`foxfire-state.json`): список
  скачанного, путь установки и настройки не теряются при перезапуске.
- Анимация загрузки каталога виджетов и понятная ошибка, если `registry.json`
  недоступен — в этом случае показываются только уже скачанные виджеты.
- Импорт профиля (`foxfirehub-profile.json`) теперь реально скачивает файлы
  виджетов, а не только обновляет список в интерфейсе.

### Изменено
- Тестовые виджеты-заглушки (`src/data/mockWidgets.ts`) больше не показываются
  в интерфейсе ни при каких условиях.

## [0.1.0-alpha.1] — 2026-09-25

Первая альфа-сборка. Ещё не для реальных стримов — часть функций работает как
заглушка для проверки интерфейса (см. README.md, раздел "Что уже работает, а
что пока заглушка").

### Добавлено
- Каркас магазина: сетка карточек виджетов, поиск, фильтр по тегам.
- Модальное окно виджета: галерея скриншотов, полное описание, настройки
  (`configSchema`), выбор и установка конкретной версии из архива версий.
- Статусы версий виджета (`stable` / `warning` / `unavailable`) с баннерами.
- Раздел "Настройки": выбор пути установки, экспорт/импорт профиля
  (`foxfirehub-profile.json`), вкладка "Внешний вид".
- Автоматическая загрузка каталога виджетов из `registry.json` на GitHub.
- Автопроверка обновлений самого приложения (`app-version.json`, баннер
  "Доступна новая версия").
- Проверка совместимости версии виджета с версией приложения
  (`minAppVersion` / `maxAppVersion` в манифесте виджета).

### Известные ограничения альфы
- Реальная загрузка и установка файлов виджета на диск не реализована —
  кнопка "Установить" только имитирует процесс.
- Кнопка "Запустить" у уже установленного виджета пока ничего не запускает.

# Changelog

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/).
Номера версий — по [SemVer](https://semver.org/lang/ru/), стадии — alpha → beta → rc → релиз.

## [0.1.4] — 2026-09-25

### Добавлено
- Реальное скачивание и распаковка файлов виджета вместо имитации установки
  (Rust-команда `download_and_extract_widget`).
- Реальное удаление файлов виджета, с выбором "сохранить настройки" или
  "удалить полностью" (Rust-команда `remove_widget_dir`).
- Вкладка "Загруженное" в нижней навигации со списком скачанных виджетов.
- Постоянное локальное состояние приложения (`foxfire-state.json`): список
  скачанного, путь установки и настройки не теряются при перезапуске.
- Анимация загрузки каталога виджетов и понятная ошибка, если `registry.json`
  недоступен — в этом случае показываются только уже скачанные виджеты.
- Импорт профиля (`foxfirehub-profile.json`) теперь реально скачивает файлы
  виджетов, а не только обновляет список в интерфейсе.

### Изменено
- Тестовые виджеты-заглушки (`src/data/mockWidgets.ts`) больше не показываются
  в интерфейсе ни при каких условиях.

## [0.1.0-alpha.1] — 2026-09-25

Первая альфа-сборка. Ещё не для реальных стримов — часть функций работает как
заглушка для проверки интерфейса (см. README.md, раздел "Что уже работает, а
что пока заглушка").

### Добавлено
- Каркас магазина: сетка карточек виджетов, поиск, фильтр по тегам.
- Модальное окно виджета: галерея скриншотов, полное описание, настройки
  (`configSchema`), выбор и установка конкретной версии из архива версий.
- Статусы версий виджета (`stable` / `warning` / `unavailable`) с баннерами.
- Раздел "Настройки": выбор пути установки, экспорт/импорт профиля
  (`foxfirehub-profile.json`), вкладка "Внешний вид".
- Автоматическая загрузка каталога виджетов из `registry.json` на GitHub.
- Автопроверка обновлений самого приложения (`app-version.json`, баннер
  "Доступна новая версия").
- Проверка совместимости версии виджета с версией приложения
  (`minAppVersion` / `maxAppVersion` в манифесте виджета).

### Известные ограничения альфы
- Реальная загрузка и установка файлов виджета на диск не реализована —
  кнопка "Установить" только имитирует процесс.
- Кнопка "Запустить" у уже установленного виджета пока ничего не запускает.

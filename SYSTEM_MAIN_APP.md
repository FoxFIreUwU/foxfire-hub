# SYSTEM_MAIN_APP.md — Дизайн-система "FoxFire Hub"

Название проекта: **FoxFire Hub**. Это оболочка-магазин помогалок/виджетов для стримеров,
оформленная в фирменном стиле бренда FoxFire (тот же стиль, что в Telegram Mini App
@foxfire_uwu_bot — тёплый почти чёрный фон + янтарно-оранжевый акцент "огня").

ВАЖНО ДЛЯ ЛЮБОГО АГЕНТА: цвета ниже сняты пипеткой с реальных скриншотов FoxFire Mini App.
Не заменяй их на фиолетовый/синий/другой "дефолтный" геймерский стиль — весь UI должен
выглядеть как родной брат FoxFire-бота.

## 1. Цветовая палитра (токены)

| Токен | HEX | Где используется |
|---|---|---|
| `bg` | `#0d0c0f` | Основной фон приложения (тёплый почти чёрный, не холодный серый) |
| `card` | `#1a1512` (обычно с прозрачностью `/80`) | Карточки виджетов, модалки, поля ввода |
| `border` | `rgba(255,255,255,0.06)` | Едва заметная рамка карточек |
| `fire` (основной акцент) | `#e2820a` | Активные кнопки, активная иконка навигации, верхняя полоса-подсветка под шапкой, ползунки-переключатели во включённом состоянии |
| `fire-dark` (hover/pressed) | `#c2690a` | Состояние наведения/нажатия на акцентных кнопках |
| `fire-glow` (свечение) | `rgba(226,130,10,0.45)` | `box-shadow` для активных элементов (неоновое свечение) |
| `success` | `#22c55e` | Зелёный бейдж рейтинга, статус "Установлено" |
| `warning` | `#eab308` | Жёлтый — версия помечена как нестабильная (см. раздел 7 в SYSTEM_WIDGET_STYLE.md) |
| `danger` | `#ef4444` | Красный — версия временно недоступна/сломана |
| `text-primary` | `#f4f0ea` (тёплый белый, не чисто-белый) | Заголовки, основной текст |
| `text-muted` | `#a89a8c` | Второстепенный текст (автор, версия, подписи) |

Фон НЕ плоский чёрный — на реальных скриншотах в тенях читается тёплый коричневатый подтон
(RGB около 13,12,15 у фона и 26,23,18 у карточек), это важно сохранить.

## 2. Карточки и поверхности

- `rounded-2xl`, `backdrop-blur-md`, `bg-card/80`, `border border-white/5` — как и раньше,
  просто акцент теперь `fire`, а не фиолетовый.
- У активных/наведённых карточек — мягкое янтарное свечение (`shadow: 0 0 20px fire-glow`),
  не фиолетовое.

## 3. Шапка (Header)

- Название приложения выводится как `FoxFire Hub 🦊🔥` (эмодзи лиса и огня — часть бренда,
  как в реальном FoxFire-боте).
- Под шапкой — тонкая горизонтальная полоса цвета `fire`, на всю ширину (как в реальном
  Mini App — там она видна прямо под хедером).
- Мелкие "эйeбрау"-подписи над заголовками (по типу "АККАУНТ" в профиле FoxFire) пишутся
  цветом `fire`, обычным (не жирным) шрифтом, без сплошного капса на весь UI — только там,
  где это реально ярлык раздела.

## 4. Нижняя навигация (Bottom Dock)

- Тёмная панель, чуть светлее фона (`#1c1712`), закреплена снизу.
- Активный раздел: иконка + подпись цвета `fire`, вокруг иконки мягкое янтарное свечение
  (как активная вкладка "Профиль"/"Главная" в реальном FoxFire Mini App).
- Разделы для FoxFire Hub: **Утилиты** (сетка карточек), **Обзор**, **Игры/Категории**,
  **Настройки** — состав можно оставить как раньше, меняется только цвет акцента.

## 5. Кнопки и переключатели

- Основная кнопка действия ("Установить/Запустить/Обновить"): заливка `fire`,
  на hover — `fire-dark`.
- Переключатели (toggle, как "Вкладка Гороскоп" в референсе): во включённом состоянии
  заливка `fire`, кружок — тёплый белый.

## 6. Функционал лаунчера (актуальный список)

1. Сетка карточек виджетов, подгружаемых из `registry.json` на GitHub.
2. Фильтрация по платформам/тегам, поиск.
3. Кнопка "Установить / Обновить / Запустить" на каждой карточке.
4. Модальное окно с деталями виджета: галерея скриншотов из GitHub-папки виджета, краткое
   описание с разворачиванием в полное, автор, теги, настройки, выбор версии.
5. **Выбор пути установки** — при первой установке (и в Настройках) пользователь может
   указать папку, куда ставятся утилиты; по умолчанию — стандартная папка приложения.
6. **Архив версий** — у каждого виджета можно посмотреть и установить не только последнюю,
   а любую из прошлых версий (см. SYSTEM_WIDGET_STYLE.md, раздел про `versions[]`).
7. **Экспорт/импорт настроек** — раздел "Настройки" содержит кнопки "Экспортировать
   настройки" и "Импортировать настройки", чтобы перенести список установленных утилит и
   их конфиги на новый ПК (например, после переустановки системы) без повторной настройки
   каждой утилиты вручную.
8. **Техобслуживание версий** — если у виджета сломанное обновление, автор помечает эту
   версию как `warning` (предупреждение, но установка разрешена) или `unavailable`
   (кнопка "Установить" заблокирована с пояснением). Подробный формат — в
   SYSTEM_WIDGET_STYLE.md.
9. Указание авторов — имя автора всегда видно на карточке и в модалке, с кликабельной
   ссылкой на его страницу (GitHub/Telegram), если она указана в манифесте.
10. **Автопроверка обновлений приложения** — при каждом запуске (и затем раз в несколько
    часов, пока окно открыто) FoxFire Hub сам сверяется с файлом `app-version.json` на
    GitHub (ссылка — `APP_UPDATE_URL` в `src/appConfig.ts`). Если вышла более новая
    версия — наверху появляется янтарная полоса с кнопкой "Скачать обновление"
    (открывает страницу релизов в браузере). Пользователю ничего не нужно нажимать
    для самой проверки — она полностью автоматическая.
11. **Проверка совместимости версии виджета с версией приложения** — у каждого виджета
    (и у каждой его версии по отдельности) можно указать минимальную/максимальную
    подходящую версию FoxFire Hub (`minAppVersion` / `maxAppVersion` в манифесте, см.
    SYSTEM_WIDGET_STYLE.md, раздел 10). Если версия приложения не подходит, установка
    этой версии виджета блокируется с понятным жёлтым предупреждением — по такому же
    принципу, как блокировка версий через `status: "unavailable"`.
